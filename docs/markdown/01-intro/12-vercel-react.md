**Next.js is open source** (MIT license) and free to use.

- It's built and maintained by **Vercel**, a hosting company — Next.js
  was originally created in 2016 by the team that later became Vercel.
- Vercel engineers work directly inside the **React** core team,
  which is why Next.js often gets React's newest features
  (Server Components, `use`, ...) before anyone else.
- You are **not locked in**: a Next.js app runs on any Node.js server,
  in Docker, or fully static — Vercel is one hosting option among
  several (we'll cover this in the last module).
