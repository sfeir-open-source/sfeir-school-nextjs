# A (short) history

Next.js ships a **major version every October**, like clockwork:

- **13.4** _(May 2023)_ — App Router marked stable, the moment it became
  the recommended way to build
- **14** _(Oct 2023)_ — Server Actions become stable
- **15** _(Oct 2024)_ — React 19 support, Turbopack stable for `dev`
- **16** _(Oct 2025)_ — Turbopack becomes the **default** bundler, for
  both `dev` and `build`

<br/>

This training is pinned to **Next.js `16.1.6`** — that's the exact
version running in every `/apps` workshop you'll touch this week.

Notes:

If asked "why does the version keep jumping so fast", the honest answer is: annual major + frequent minors, and the framework has been remarkably good at shipping codemods for breaking changes.
