# The root layout: the one you can't skip

Every Next.js app has exactly one **root layout** — `app/layout.tsx`, at the
top of the `app/` folder. It's the only layout that's **mandatory**, because
it's the one responsible for the actual `<html>` and `<body>` tags:

<small>

```tsx
// app/layout.tsx
import { Metadata } from 'next';
import './global.css';

export const metadata: Metadata = {
  title: 'Welcome to bootstrapping',
  description: 'Generated by create-nx-workspace',
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

</small>

- This is the exact file sitting at `01-layout/src/app/layout.tsx` right now.
- Every single page in the app renders somewhere inside its `{children}` —
  directly, or through more layouts nested in between.
- It's also where app-wide concerns belong once you meet them: global CSS,
  fonts, providers.

Notes:

If someone asks "can I have zero layouts?" — no, this one file is non-negotiable, create-next-app always scaffolds it. Keep the "app-wide concerns" bullet light — don't define providers or fonts in depth, just plant the flag for later.
